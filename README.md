# 🏫 Цифровая платформа администрации школы (Streamlit)

Платформа для школы для одарённых детей (РК): роли администрации и специалистов, документооборот,
электронный архив на GitHub, поручения с галочками, отзывы учителей с автоанализом, план развития школы (МДЖ)
со SWOT, рейтинг учащихся, «Ступени», лист наблюдения урока, журнал взаимопосещения, работа завхоза, соцпедагога,
психолога, НВП, физкультуры, профорга, библиотеки и столовой.

Полное описание функций и автоматизации — в [PROMPT.md](PROMPT.md). Стоимость хранения — в [docs/COSTS.md](docs/COSTS.md).

## Быстрый старт локально
```bash
pip install -r requirements.txt
cp .streamlit/secrets.toml.example .streamlit/secrets.toml   # впишите ADMIN_PASSWORD
streamlit run app.py
```
Без секретов базы данных программа работает на локальной SQLite (`school.db`), а архив — в папке `archive/`.

## Развёртывание (бесплатно)
1. **GitHub (код):** создайте репозиторий `school-admin` и загрузите туда содержимое этой папки
   (`git remote add origin https://github.com/aidarpavl/school-admin.git && git push -u origin main`).
   Файл `.streamlit/secrets.toml` в GitHub **не попадает** (он в `.gitignore`).
2. **GitHub (документы):** создайте **приватный** репозиторий `school-docs-2026-2027` с README (чтобы была ветка main).
   Создайте fine-grained токен: GitHub → Settings → Developer settings → Fine-grained tokens →
   доступ только к репозиториям `school-docs-*`, разрешение **Contents: Read and write**.
3. **Supabase:** создайте проект → SQL Editor → выполните `sql/supabase_schema.sql` →
   Connect → **Session pooler** → скопируйте URI в `DATABASE_URL` (прямое подключение Streamlit Cloud не поддерживает — нужен pooler).
4. **Почта для восстановления пароля:** Gmail → включите 2FA → «Пароли приложений» → 16-значный пароль в `SMTP_PASSWORD`.
5. **Streamlit Community Cloud:** New app → репозиторий `school-admin`, файл `app.py` →
   Settings → Secrets → вставьте содержимое `secrets.toml.example` со своими значениями.
6. Войдите как главный админ → «Электрондық мұрағат» → «⚙ Баптау» → **«Папкалар құрылымын құру»** —
   программа создаст все папки в GitHub.

## Безопасность
- Пароли хранятся только в виде хэша PBKDF2-SHA256.
- Пароль главного админа задаётся в Secrets, а не в коде. **После первого входа смените его в «⚙ Профиль».**
- Журналы психолога и соцпедагога видят только их авторы и директор/админ.
