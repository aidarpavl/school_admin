| Что | Вариант | Цена | Лимиты | Вывод |
|---|---|---|---|---|
| Таблицы (пользователи, задачи, журналы, отзывы) | **Supabase Free** | 0 ₸ | БД 500 МБ, 1 ГБ файлов, 5 ГБ трафика; проект **засыпает после 7 дней без активности** | ✅ Текстовых записей школы хватит на годы |

| | Supabase Storage | 0 ₸ / в Pro | 1 ГБ бесплатно | ❌ мало для 2–4 ГБ |

## Рекомендуемая схема (0 ₸ в месяц)
1. **Код программы** → GitHub `aidarpavl/school-admin` (публичный или приватный) → Streamlit Community Cloud.
2. **База данных** → Supabase Free (PostgreSQL). Чтобы проект не засыпал на каникулах — заходите в программу хотя бы раз в неделю
   (или настройте бесплатный пинг, например UptimeRobot).
3. **Электронные документы** → **приватный** репозиторий `aidarpavl/school-docs-2026-2027`.
   На следующий учебный год программа сама переключится на `school-docs-2027-2028` (шаблон `{year}` в секретах) —
   так каждый репозиторий остаётся меньше 5 ГБ.
4. **Видео, фото с мероприятий, сканы > 50 МБ** → Google Drive, в документ вставляется ссылка.

## Почему документы не в репозитории программы
Streamlit Cloud при каждом запуске скачивает весь репозиторий приложения. Если там будет 4 ГБ документов,
запуск станет очень медленным или будет падать. Поэтому код и документы — в разных репозиториях.
