# СУПЕР-ПРОМТ: «Цифровая администрация школы для одарённых детей (Республика Казахстан)»

> функции каждого члена администрации и специалистов школы, способы автоматизации их работы
> и техническое задание на программу. Приложение в этом репозитории построено по этому промту.

## 0. Роль ИИ

Ты — эксперт по управлению организацией образования Республики Казахстан (специализированные
школы и школы для одарённых детей: РНПЦ «Дарын», НИШ, ОСШ-лицеи, гимназии), аналитик бизнес-процессов
и senior Python-разработчик (Streamlit + PostgreSQL/Supabase). Ты знаешь действующие НПА Министерства
просвещения РК: Типовые правила деятельности организаций образования, перечень документов, обязательных
для ведения педагогами, правила аттестации педагогов, правила оценивания (СОР/СОЧ — БЖБ/ТЖБ),
программу «Адал азамат», требования к работе социального педагога и педагога-психолога,
к начальной военной и технологической подготовке (НВТП / АӘТД) и физической культуре.
Перед ссылкой на конкретный номер приказа — проверяй его актуальность (adilet.zan.kz).

Язык интерфейса: **қазақ тілі** (основной) + русский. Документы формируются на языке обучения.

## 1. Цель

Создать единую веб-платформу школы, которая:
1. Переводит в цифру всю документацию администрации, педагогов, методкабинета и специалистов.
2. Автоматизирует рутину: формы, журналы, отчёты, сводки, напоминания, контроль исполнения.
3. Даёт администрации аналитику и рекомендации (отзывы педагогов, SWOT, МДЖ, рейтинги).
4. Работает по логину/паролю с ролями, восстановлением пароля по e-mail и главным админом.

## 2. Роли и их функции + что автоматизировать

### 2.1 Директор / Главный администратор
**Функции:** общее руководство, утверждение документов, распределение обязанностей, контроль исполнения,
стратегия (Мектептің даму жоспары — МДЖ), кадры, финансы, взаимодействие с отделом/управлением образования.
**Автоматизация:**
- Матрица распределения обязанностей между членами администрации (галочки «кто за что отвечает»).
- Поручения с дедлайнами и галочкой «Орындалды», % исполнения по каждому сотруднику, просрочки.
- Входящие на утверждение документы (статусы: Жоба → Жіберілді → Қаралуда → Бекітілді/Қайтарылды).
- Дашборд: задачи, документы, настроение коллектива по отзывам, рейтинг учащихся, энергопотребление.
- Управление пользователями и ролями.

### 2.2 Заместитель директора по учебной работе (Оқу ісі жөніндегі орынбасар)
**Функции:** учебный план и РУП, расписание, тарификация/нагрузка, контроль ведения электронного журнала
(Kundelik/Bilimal), мониторинг БЖБ/ТЖБ, качества знаний и успеваемости, внутришкольный контроль (ВШК),
посещение уроков (лист наблюдения урока, 0–3 балла по критериям), подготовка к ВОУД/ЕНТ/МОДО,
итоговая аттестация, работа с неуспевающими, замены уроков, отчёты в отдел образования.
**Автоматизация:**
- Электронный «Лист наблюдения урока» (планирование, обучение, оценивание, рефлексия; 0–3 балла;
  автоподсчёт итога и уровня; рекомендации голосом/текстом; экспорт в Word).
- Загрузка CSV с оценками → автоматический расчёт % качества и успеваемости по классам/предметам/учителям.
- План ВШК с ответственными и сроками → автоматические поручения.
- Журнал замен уроков с подсчётом часов. Справки по итогам ВШК — по шаблону.

### 2.3 Заместитель директора по воспитательной работе (Тәрбие ісі)
**Функции:** план воспитательной работы, «Адал азамат», «Біртұтас тәрбие», классные руководители,
школьное самоуправление (парламент), профилактика правонарушений, работа с родителями,
кружки и секции, летний отдых, внеурочная деятельность, совместная работа с соцпедагогом и психологом.
**Автоматизация:**
- Календарь мероприятий с ответственными и охватом учащихся → автоотчёт за месяц/четверть.
- Отчёты классных руководителей (единая форма) → сводная таблица по школе.
- Учёт кружков и занятости учащихся (% охвата). Учёт родительских собраний.

### 2.4 Заместитель директора по информатизации (Ақпараттандыру)
**Функции:** цифровая инфраструктура, учёт техники, интернет, сайт и соцсети школы, Kundelik/Bilimal,
электронный документооборот, кибербезопасность, цифровая грамотность педагогов, ЦОР.
**Автоматизация:**
- Инвентаризация техники (кабинет, инв. номер, состояние) → список на ремонт/списание.
- Заявки «IT-көмек» со статусами. Учёт публикаций на сайте/соцсетях.
- Мониторинг заполнения электронного журнала. Учёт курсов по цифровой грамотности.

### 2.5 Заместитель директора по инновациям и кадрам (Инновация және кадр)
**Функции:** кадровый состав, аттестация (педагог-модератор/эксперт/исследователь/мастер), курсы
повышения квалификации, молодые специалисты и наставничество, Lesson Study, исследования в действии,
инновационные проекты, обобщение опыта, конкурсы педмастерства.
**Автоматизация:**
- База педагогов: категория, срок аттестации → автоматический список «аттестация в этом году».
- Учёт курсов (часы, сертификаты). Журнал взаимопосещения уроков молодых педагогов (с экспортом в Word).
- Наставничество: пары «наставник — молодой специалист», план и отчёт.

### 2.6 Заместитель директора по работе с одарёнными детьми (Дарынды балалармен жұмыс)
**Функции:** выявление одарённости, банк данных одарённых, олимпиады (школьный→республиканский→международный),
научные проекты (МАН/«Зерде»/«Дарын»), индивидуальные траектории, подготовка к конкурсам, рейтинг учащихся.
**Автоматизация:**
- Банк одарённых детей и результатов олимпиад/конкурсов (уровень, место, наставник).
- Рейтинг учащихся с автоматическим подсчётом баллов по категориям (учёба, олимпиады, спорт, творчество,
  общественная активность) и таблицей лидеров по классам.
- Отчёт для РНПЦ «Дарын»/управления одним нажатием.

### 2.7 Методический кабинет (Әдістемелік кабинет)
**Функции:** методические объединения, педсоветы, методсоветы, открытые уроки, семинары, обобщение опыта,
методическая помощь, экспертиза авторских программ.
**Автоматизация:** протоколы МО/педсовета, план открытых уроков, документооборот «учитель ↔ методкабинет ↔ администрация».

### 2.8 Завхоз (Шаруашылық меңгерушісі)
**Функции:** материально-техническая база, ремонт, инвентарь, санитарное состояние, пожарная и
антитеррористическая безопасность, коммунальные услуги, экономия электроэнергии, столовая (совместно).
**Автоматизация:**
- Заявки на ремонт с приоритетом и статусом. Инвентарный учёт.
- Показания счётчиков (электричество, вода, тепло) → график расхода и экономии.
- Модуль энергосбережения «ЭкоСвет»: https://ecosvetzhd.streamlit.app/
- Кнопка «Асхана жұмысы» (заявка столовой): https://zhd-stolovaya-zaiavka.streamlit.app/

### 2.9 Социальный педагог (Әлеуметтік педагог)
**Функции:** социальный паспорт школы, учёт детей из многодетных/малообеспеченных семей, сирот, детей с ООП,
внутришкольный учёт и учёт ПДН, бесплатное питание, всеобуч, акты обследования ЖБУ, рейды, защита прав детей.
**Автоматизация:**
- Социальный паспорт: учащийся + категории → автоматический подсчёт по категориям и классам.
- Журнал посещений семей (актов), рейдов, профилактических бесед. Список на бесплатное питание.
- Автоотчёт «Әлеуметтік паспорт» в Word.

### 2.10 Педагог-психолог
**Функции:** диагностика (адаптация 1/5/10 классов, тревожность, профориентация, суицидальный риск),
консультации учащихся/родителей/педагогов, коррекционно-развивающая работа, группа риска, психопросвещение.
**Автоматизация:**
- Журнал диагностики с уровнем риска → автоматический список «группа риска» (конфиденциально, доступ только
  психологу и директору). Журнал консультаций. Сводная статистика по классам. Отчёт в Word.

### 2.12 Преподаватель-организатор НВТП (АӘТД)
**Функции:** начальная военная подготовка 10–11 кл., приписка юношей, учебно-полевые сборы, военно-патриотические
мероприятия, гражданская оборона, тренировочные эвакуации.
**Автоматизация:** список допризывников, нормативы (стрельба, разборка АК, строевая) с оценкой, журнал мероприятий
и эвакуаций, отчёт.

### 2.13 Учитель физической культуры
**Функции:** уроки, нормативы, группы здоровья, спортивные секции, соревнования, Президентские тесты.
**Автоматизация:** результаты нормативов с автоматическим выставлением оценки по таблице, учёт групп здоровья,
соревнования и призовые места (уходят в рейтинг учащихся).

### 2.14 Профорг (Кәсіподақ)
**Функции:** учёт членов профсоюза, взносы, коллективный договор, материальная помощь, поздравления,
культурно-массовые мероприятия, протоколы профсобраний, охрана труда.
**Автоматизация:** реестр членов, заявления на материальную помощь (со статусом), протоколы, мероприятия;
дни рождения коллег: https://personalbirthdayzhd.streamlit.app/

### 2.15 Учитель
**Функции:** КТП/КСП, журналы, БЖБ/ТЖБ, классное руководство, работа с одарёнными, самообразование.
**Автоматизация:** отправка документов на проверку (КТП, планы, отчёты) с историей статусов, предложения и
отзывы администрации (можно анонимно), участие во взаимопосещении, личный кабинет задач.

## 3. Сквозные модули

1. **Авторизация:** логин/пароль (хэш PBKDF2), регистрация с e-mail, восстановление пароля кодом по почте,
   смена пароля. Главный администратор задаётся через секреты (не хранить пароль в коде/GitHub!).
2. **Поручения + распределение обязанностей** (галочки), прогресс в %.
3. **Документооборот:** администрация ↔ учителя ↔ методкабинет; вложения (Supabase Storage / ссылка Google Drive),
   маршрут по роли или конкретному человеку, история действий, резолюции.
4. **Предложения и отзывы** учителей (адресуются конкретной роли) → автоматический анализ: тональность,
   темы, частота, приоритет → рекомендации администрации (правила + опционально ИИ через API).
5. **Лист наблюдения урока завуча** и **журнал взаимопосещения молодых педагогов** (как в исходных HTML-формах:
   голосовой ввод, экспорт в Word).
6. **Рейтинг учащихся** (как reytingstudentszhd2026).
7. **«Ступени»** — отдельная глава (встраивание приложения stupeni.streamlit.app) + отзывы по ролям.
8. **МДЖ:** ответы анкеты https://talismasters.streamlit.app/ → SWOT → администрация по разделам добавляет
   темы и предложения → кнопка «МДЖ құрастыру» собирает план → экспорт в Word.
9. **Отчёты:** любой журнал → сводка (кол-во по категориям, средние) → CSV/Word одним нажатием.

## 4. Техническое задание

- Python 3.11+, Streamlit, PostgreSQL (Supabase, бесплатный тариф) — локально SQLite для разработки.
- Файлы: Supabase Storage (1 ГБ бесплатно) или ссылки Google Drive (Google Workspace for Education — бесплатно).
- Репозиторий GitHub → деплой на Streamlit Community Cloud. Секреты — в Settings → Secrets.
- Таблицы: users, reset_codes, tasks, duties, documents, doc_history, feedback, records (универсальный JSON-журнал).
- Права: каждый видит своё; администрация — всё по своему направлению; конфиденциальные журналы психолога и
  соцпедагога — только их владельцам и директору/админу.
- Экспорт документов в Word (.doc) и CSV. Интерфейс адаптивен для телефона.
